# 原文图片计数与裁剪

## 先确定数量与边界

通读编号及图注，建立“编号—PDF物理页码—图注—位置”的清单。按 Fig./Figure、图或原文其他标签核对正文引用，区分 Table、Scheme、图形摘要和补充图。同一图中的 A–H 等分面通常计为一张图，多个 PDF 图片对象或矢量路径不能用来判断图数。

扫描件需要页面视觉检查或 OCR 辅助；不能只按文本搜索结果漏掉图。只拿到正文 PDF 时，不宣称已经统计未提供的补充材料。

## 找裁剪框

先渲染含图页面的预览，目视确定每张图的边界。标出完整图内文字、所有面板、图例、坐标及比例尺，同时排除图外标题说明、图注、页眉页脚、邻栏正文和多余空白。保留少量白边，不能紧贴笔画或数据点。

首页信息图使用同样流程：保留完整期刊题名和全部作者区域；是否保留 DOI、日期、单位依用户与样例。若无关正文位于所需区域之间，允许精确裁下后拼接，并核对阅读顺序。

## 可复现清单

`scripts/crop_pdf_regions.py` 接受 UTF-8 JSON。矩形坐标采用 **pdftoppm 渲染图像的左上角原点、归一化坐标**，每值介于0和1。先看实际渲染图，设其像素宽高为 W、H，将 `(left/W, top/H, right/W, bottom/H)` 写入 bbox。这样避免不同 DPI 的坐标混用，也避免 PDF 旋转页的原始坐标误差。

```json
{
  "expected_figure_count": 2,
  "items": [
    {"kind": "metadata", "name": "期刊、题目、作者信息图", "page": 1, "bbox": [0.05, 0.02, 0.95, 0.30]},
    {"kind": "figure", "number": 1, "name": "图1", "page": 2, "bbox": [0.10, 0.06, 0.90, 0.60]},
    {"kind": "figure", "number": 2, "name": "图2", "page": 3, "bbox": [0.08, 0.06, 0.92, 0.75]}
  ]
}
```

上述框仅用于说明格式，每篇论文都需重新测量。`page` 从1开始，表示PDF文件中的物理页码。输出为 `<name>.png`，name 不带扩展名。仅处理某几张图时，计数对应本次请求范围，保留原图号。

```text
python scripts/crop_pdf_regions.py --pdf <paper.pdf> --manifest <work/crops.json> --out-dir <outputs/论文插图> --work-dir <work/crop-renders> --dpi 400 --report <work/crop-report.json>
```

Python 需 Pillow，系统需 Poppler 的 pdftoppm（可通过 `--pdftoppm` 指定）。使用应用提供的工作区依赖运行时，不假定系统 Python 已安装模块。脚本默认拒绝覆盖现有 PNG；确需更新本次交付图时可加 `--overwrite`。脚本只裁矩形、保留原像素，不会自动识别图、清除图注或保证语义完整。

## 最终检查

以300–400 DPI为常用起点，小标签或复杂矢量图可提高；避免仅靠上采样制造清晰度。优先保留 PNG，检查每张实际输出：边界无截断、标签与图例完整、无图外正文、图号对应、分辨率足够。可做总览联系表用于计数，但不能代替逐张放大检查。

多页延续图需分别裁剪后拼接或按“图N_续”保存，并说明构成。表格跨页时单独处理。保留裁剪清单和来源哈希在 `work/`，最后交付图片目录及需要的 ZIP。
